# Third-party licenses

The MIT license covers original KERNEL//LAB code. Kernel source, headers and tooling imported by users retain the upstream license and notices. No external Linux source tree is included here.

The exact external dependency versions are recorded in the Rust and npm lockfiles. Retain dependency notices when redistributing binaries or browser bundles. Major dependencies include Rust libraries such as Tokio (MIT), SQLite (public domain), React (MIT), Monaco (MIT), and Tauri (MIT or Apache-2.0). Consult each version's package license for its terms.
