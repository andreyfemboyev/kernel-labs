# ABI and KMI

Compare Module.symvers exports with `klab abi compare BASE CANDIDATE`. The report identifies additions, removals, and changes to CRC, exporting module, export class and namespace. Its compatibility classification applies to observed metadata only. Evaluate additional kernel and module build properties for runtime compatibility. [Android ABI monitoring](https://source.android.com/docs/core/architecture/kernel/abi-monitor) · [Stable KMI](https://source.android.com/docs/core/architecture/kernel/stable-kmi)
