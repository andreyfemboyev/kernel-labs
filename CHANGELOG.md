# Changelog

## v0.1.0-alpha

- Added a standalone CLI and shared Rust workspace, build and inspection libraries.
- Added SQLite imports, history and audit records, four build adapter plans, structured process logs, Unix cancellation, and artifact checksums.
- Added local configuration, ELF, module, Module.symvers, DTB, boot image and kernel log inspection.
- Added a Tauri and React workbench source tree with artifact inspection, a build console, Monaco scratch editing and English and Russian interface labels.
- Added build and parser fixtures, an export plugin example, and CI and packaging workflows.

See the [compatibility matrix](docs/LIMITATIONS.md) for verified scope.
