# Roadmap

1. Verify real Linux and Android builds across Kbuild, Kleaf and legacy branches. Add per-profile history, stronger process lifecycle supervision, and workspace source indexing.
2. Add persistent source sessions and a desktop build console. Expand authoritative Kconfig integration, Device Tree overlays and schema checks, and kernel binary comparison.
3. Add module builds, STG workflows, structured boot-image and AVB validation, and automatic diagnostics symbolization.
4. Verify native packaging and runtime smoke tests on Linux x86_64, Linux ARM64 and Windows with WSL2. Wire a typed WSL2 build bridge.
